# Changelog

## 1.0.0

First release. Forked from [picocolors](https://github.com/alexeyraspopov/picocolors).

- Added extended underline styles: `underlineDouble`, `underlineCurly`, `underlineDotted`, `underlineDashed`.
- Added `overline`.
- Added underline colors (`underlineRed`, `underlineRedBright`, …), derived from [yoctocolors](https://github.com/sindresorhus/yoctocolors).
- Dropped browser support.
